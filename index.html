// The problem

Half the factory speaks a different language

Daikibo's manufacturing infrastructure streams telemetry from thousands of IIoT devices. Half of them emit a flat structure — everything at the top level, location packed into a single slash-separated string.

The other half emits a nested structure — device info tucked inside a device object, location split across five fields, and timestamps as ISO 8601 strings instead of epoch milliseconds.

Same information. Different shapes. Downstream systems can't process them together. The fix: convert both into a single unified model.
